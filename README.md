# 🛒 MERN E-Commerce App

A full-stack E-Commerce application built using the MERN stack (MongoDB, Express.js, React.js, Node.js).  
The app includes authentication, product management, cart functionality, online payments, and an admin dashboard.

---

# 🚀 Tech Stack

## Frontend
- React.js
- Redux Toolkit
- React Router DOM
- Axios
- Tailwind CSS 

## Backend
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT Authentication

# ▶️ Run Locally

## 1. Install Dependencies

### Backend

```bash
cd backend
npm install
```

### Frontend

```bash
cd frontend
npm install
```

---

# 🚀 Start the Application

## Run Backend

```bash
cd backend
npm run dev
```

Backend runs on:

```bash
http://localhost:5000
```

## Run Frontend

```bash
cd frontend
npm start
```

Frontend runs on:

```bash
http://localhost:3000
```
